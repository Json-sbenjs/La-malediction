# Charte graphique

- Page de la charte (couleurs, typo, blason, illustrations, aperçus) : https://claude.ai/artifact/HaeBA24jCAPN1vucGuhNkZ
- `README.md` : le livre de marque (copie du texte de la page).
- `tokens.json` : les couleurs (thèmes Nuit et Jour), la typo, les espacements, les arrondis et les ombres.
- Les images sont dans `public/` : `blason.webp`, les icônes, et `public/roles/<rôle>.webp` (les 28 illustrations des cartes).
